## 6. AI diagnostic evaluation / AI 诊断评估

`ai_cases.json` contains 12 synthetic reasons drafted with AI, including concept errors, slips, insufficient evidence and instruction injection. The expected labels are provisional. Preserve the original learner text; translations are explanatory material, not identical evaluation inputs.

`ai_cases.json` 有 12 条 AI 起草的模拟理由，覆盖概念错误、手误、证据不足及指令注入。标签仅初稿。应保留原始理由；翻译可供理解，但不是完全相同的模型输入。

```text
python scripts/evaluate_ai.py
python scripts/evaluate_ai.py --live
```

The first command generates a free rule baseline; `--live` may make 12 paid calls with no automatic retries. This audit did not run either a paid model evaluation or invent a score. The current script uses Chinese analysis by default, so English behaviour needs a separate recorded evaluation.

第一条生成免费规则基线；`--live` 可发出 12 次付费请求，无自动重试。本次未执行付费评估，也未编造分数。脚本默认中文分析，英文模型效果需单独评估。

Evaluation procedure / 评估步骤：

1. Two independent labels, adjudication, fixed labels and a separate untouched holdout. / 两人独立标注、讨论分歧、冻结标签，另留未调试保留集。
2. Run rules and AI on the same cases; record model, language, date and configuration excluding secrets. / 同样本对比规则与 AI，记录模型、语言、日期及不含密钥的配置。
3. Count valid AI outputs separately from fallbacks. / 有效 AI 与回退分开统计。
4. Report concept agreement, unknown detection and both valid-only and whole-pipeline results with explicit denominators. / 报概念一致率、unknown 识别、有效输出子集和全流程结果，写明分母。
5. Human-score factual correctness and relevance, each 0/1/2 with explanations. / 人工对事实正确性、针对性各评 0/1/2 并说明依据。
6. Discuss improved and failed cases, not just averages. / 同时展示改善与失败案例。

|---|---|---|---|---|---|---|
| Not run / 未运行 | 12 provisional synthetic cases / 12 条模拟初稿 | Not assessed / 未评估 | Not verified / 未验证 | Not verified / 未验证 | To fill / 待填写 | To fill / 待填写 |

This is an outline, not a completed individual submission. Each member should produce 650–800 English words, then add a Chinese translation for review if permitted. Export a PDF. Do not count copied translation as a substitute for the minimum substantive report.

中文提示：解释实际应用的 Python 概念与一条被核实、修改或拒绝的 AI 建议，以及所学。
