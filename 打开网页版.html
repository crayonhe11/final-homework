Open PySteps
打开 PySteps 本机网页版

In the project folder, run python main.py --open.先在项目文件夹运行上述命令。

macOS: python3 main.py --open
Windows: py main.py --open按本机 Python 命令选择，需先安装 Python。

Once the server starts, open the local learning page / 进入本机学习页面. If you selected another port, use the URL printed in the terminal.服务启动后再进入页面；指定其他端口时，使用终端显示的网址。此文件不会自动启动服务。

Local use needs no VPN. Remote team access requires a reachable server; see README.md.本机无需 VPN。团队远程访问需要可连接的服务器，详见 README.md。
