# 跨平台使用说明

适用对象：Python初学者的个人学习工具，不包含教师端。

## 安装条件

三个平台都需要Python 3.10+、Tkinter和图形桌面。Python程序本身没有额外pip依赖。选择题、知识地图、记录、AI和统计不依赖Docker；只有Windows/Linux上的代码运行与判题需要Docker。

| 系统 | 启动方式 | 代码判题方式 |
|---|---|---|
| macOS | 双击启动.command | 默认系统sandbox-exec隔离，无需Docker |
| Windows | 双击启动.bat | Docker Desktop，使用Linux容器模式 |
| Linux | 运行sh 启动.sh | 已启动并可由当前用户访问的Docker Engine |

Windows安装Python时需包含Tkinter（通常安装包已包含）；若命令不可用，检查Python启动器或PATH。Linux发行版可能需另装Tkinter，例如Ubuntu/Debian为sudo apt install python3-tk。无图形桌面的服务器只能运行python3 main.py --cli，该模式只提供基础选择题流程，不含完整桌面编程体验。

Docker安装参考：
- Windows：https://docs.docker.com/desktop/setup/install/windows-install/
- Linux：https://docs.docker.com/engine/install/

请使用官方支持的系统版本及安装方式。Windows需要Docker能运行Linux容器；仅安装Docker命令行但未启动守护进程不能判题。不需要对外开放Docker端口，也不要为了方便关闭系统保护。

## Windows首次准备

1. 安装Python和Docker Desktop，启动Docker Desktop并确认处于Linux容器模式。
2. 打开终端，进入项目文件夹，执行：

```sh
docker pull python:3.13-slim
py -3 tools/check_environment.py
```

3. 双击启动.bat，在章节编程区运行示例。

下载镜像只需在首次使用或主动更新时进行。程序运行学生代码时不会自动下载镜像。启动脚本支持Python启动器py -3，若没有则尝试python。

## Linux首次准备

安装带Tkinter的Python及Docker Engine，并确保当前用户能访问已运行的Docker守护进程。随后在项目目录执行：

```sh
docker pull python:3.13-slim
python3 tools/check_environment.py
sh 启动.sh
```

宿主机不直接执行学生代码；Python代码通过标准输入传入隔离容器，路径含空格或中文时也不需要挂载项目目录。

## macOS

继续双击启动.command即可，原本的Mac沙盒仍为默认方式。检查本机环境：

```sh
python3 tools/check_environment.py
```

如需专门验证Docker后端，在安装并启动Docker、下载镜像后执行：

```sh
EDU_CODE_BACKEND=docker python3 main.py
```

EDU_CODE_BACKEND只选择运行后端，不涉及API密钥。auto为默认值，native只允许macOS，docker明确要求Docker；不会降级为无隔离运行。

## 运行保护和错误处理

Docker容器禁用外部网络、根文件系统只读、非root用户运行、丢弃额外权限；不挂载宿主目录，不传递Kimi密钥。设置128MiB内存与同等内存+交换总量、32进程、1CPU配额，worker仍有CPU时间及输出限制。每次生成独立容器，正常完成、错误或超时后只清理本次容器。

容器准备最多等待12秒；开始执行后默认墙钟限制4秒，清理最多等待5秒。Docker启动开销也计入执行等待，首次运行可能稍慢。若Docker无响应导致无法确认清理，会给出本次容器名称，需重启Docker后检查。没有Docker、服务未启动、镜像缺失或非Linux模式时可继续编辑与保存草稿，但不能执行代码。

Docker客户端使用当前用户配置的Docker上下文，团队应使用本机的Docker；不要在不知情的情况下选择远程守护进程。本方案仍是本地教学工具，不是经过安全认证的公网不可信代码服务。

隔离参数参考：https://docs.docker.com/engine/containers/run/

## 目标机器验收

完成安装后，先用6道参考答案验证正常判题，再检查错误答案、空输入、无限循环和输出过长。可显式运行Docker实测集：

Windows PowerShell：

```powershell
$env:PYTHONUTF8="1"
$env:EDU_RUN_DOCKER_TESTS="1"
$env:EDU_CODE_BACKEND="docker"
py -3 -m unittest discover -s tests -p test_crossplatform.py -v
```

Linux/macOS：

```sh
EDU_RUN_DOCKER_TESTS=1 EDU_CODE_BACKEND=docker python3 -m unittest discover -s tests -p test_crossplatform.py -v
```

该测试不调用AI或付费API。新增GitHub Actions工作流包含三个系统的普通测试，以及Linux Docker真实集成测试；需要项目提交到GitHub后由实际运行产生结果，不代表已经通过CI。
