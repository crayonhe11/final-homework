|---|---|---|

## 建议里程碑

1. 全员启动程序，教育成员与编程成员复核 30 题。
2. 根据反馈调整界面和题目，完成需求验收表。
3. 接入团队可运行的本地模型，冻结调试版本。
4. 用独立评估集比较规则与 AI，记录失败案例。
5. 完成代码交叉审查、演示排练和个人报告。

## 五分钟演示

选循环主题 → 找到 range 边界题并选包含终点的错误答案 → 查看规则线索 → 完成推荐的变式 → 展示错题回顾和进度 → 演示未配置模型仍能用 → 若已运行模型，展示“概念错误/手误”的真实比较结果 → 说明评估局限。
