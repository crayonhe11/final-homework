# 界面参考与改版

## 参考来源

- [Kolibri GitHub](https://github.com/learningequality/kolibri) 与其 [官方学习指南](https://kolibri.readthedocs.io/en/latest/learn.html)：参考学习导航、内容层级、课程进入方式、练习反馈与继续学习的组织方式。
- [Moodle GitHub](https://github.com/moodle/moodle) 与其 [官方课程概览说明](https://docs.moodle.org/502/en/Course_overview)：参考课程卡片、完成进度和课程概览的信息结构。

只借鉴信息组织和交互原则。颜色、桌面布局及组件为本项目独立实现，没有复制第三方源码、商标或素材，也没有把整个网站平台移植进来。

## 本次实际修改

1. 固定左侧导航，区分课程地图、练习工作区、错题记录和学习进度，当前页面明确高亮。
2. 课程首页增加继续学习主入口和三张真实数据卡：课程完成、已练习题目、待复习。
3. 章节使用白色卡片、独立进度条、关卡序号与状态，支持双击打开课程。
4. 地图在窄窗口自动变为两列或一列，长内容通过地图滚动条查看。
5. 练习工作区左右分栏：左侧阅读代码、选择答案、填写理由；右侧解析反馈和下一步推荐。
6. 深色等宽代码区、紫色主要操作、统一标题层级、浅色背景与白色内容卡。
7. 使用统一 ttk 主题，减少系统深色模式与浅色文本框混用带来的割裂。
8. 窗口标题改为“知错 · Python 学习平台”，便于识别新版。

## 保留的行为

课程阅读、双击导航、前置关卡解锁、提示使用记录、自由练习、AI回退、错题回顾、间隔复习和数据库结构保持原逻辑。本次不新增外部依赖，不改为网站，不伪造学习进度。

## 验证与边界

原有41项自动测试通过；桌面导航、课程闯关及旧功能回归通过。平台界面检查覆盖侧栏切换、课程数据卡、窄窗口滚动和分栏区域。个人学习数据保留，更新前备份。

本轮主要是界面改版，之前未完成的个性化大模型反馈、教师汇总及人工审核仍按《功能完成情况》列明，不因换界面就视为完成。
