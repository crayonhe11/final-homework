# 实现自查记录

本文件是生成与实现过程的自查，不替代六人团队真实的同行审查。

| 检查点 | 处理与验证 |
|---|---|
| 标准答案正确性 | 30 题在隔离 Python 子进程内逐一执行，输出与标准选项一致 |
| 学生代码执行 | 应用不执行学生代码；只保存文字理由 |
| 推荐立即重复原题 | engine 明确排除当前题号，测试覆盖全部题目 |
| 原因过度归因 | 规则与 AI 均使用可能性表述；AI 可输出 unknown |
| AI 输出越界 | 检查候选标签、JSON 结构、引用长度及原文存在性 |
| AI 调用失败 | 超时、无效 JSON 等回退规则，不阻断记录保存 |
| UI 线程安全 | 后台线程仅分析，队列传回主线程后再更新界面 |
| 重复提交 | 分析期间禁用提交和换题，成功提交后禁用原题再次提交 |
| 持久化与输入安全 | 参数化 SQL、事务保存；测试包含类似 SQL 注入的理由 |
| 进度误导 | 重复答对同一道题不会被标为初步稳定 |
| 研究结论边界 | 模拟标签一致率与真实教育效果分开说明 |

待团队完成：教育标签复核、不同操作系统可用性、真实模型延迟和诊断案例、独立同行代码审查。
