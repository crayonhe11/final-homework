# 当前功能清单（2026-10-11）

定位：面向Python初学者的个人学习、概念诊断与练习推荐工具。教师端不属于当前范围。

| 模块 | 已实现内容 | 使用条件或限制 |
|---|---|---|
| 知识体系 | 基础导学，条件判断/循环/函数与返回值三章，15个概念；双击进入讲解 | 内容仍需团队教育与编程成员复核 |
| 学习闯关 | 前置关系、阅读状态、每关两道检查、过关解锁 | 过关不等于永久掌握 |
| 选择题练习 | 30题、正误判断、标准解析、分级提示、文字理由 | 自由练习不计课程闯关 |
| 操作流程 | 提交后原位置变为下一题/继续本关/查看下一课 | 不自动跳题 |
| 趣味编程 | 每章2个原创任务，共6题；章节入口与分组总览；无需先完成选择题 | 受控Python子集，不支持任意导入/文件/网络代码 |
| 编辑与判题 | 语法着色、缩进、草稿、示例、全部测试、错误位置与返回值比较 | macOS原生沙盒；Windows/Linux新增Docker后端，后两者待实机验收 |
| 概念诊断 | 错误选项规则映射，Kimi依据学生理由辅助诊断 | 仅答错且理由非空；只能选候选概念或unknown |
| 个性化讲解 | AI生成本题解释和思考提示，保留标准解析，失败回退 | 格式/引用检查不能保证语义正确，真实质量待评估 |
| 练习推荐 | 同概念变式、到期复习、难度排序、避免当前题；AI证据不足时改中性验证 | 只选固定题库，不生成未经核验的新题 |
| 学习记录 | SQLite本地保存、选择题错题回顾、重练与JSON导出 | 代码提交已保存，逐次代码历史回放页面尚未实现 |
| 学习进度 | 知识地图、概念明细、7/30/90天次数与正确率曲线、章节筛选 | 选择题和编程统计分别显示 |
| API配置 | 项目api_config.json配置Kimi，Git忽略真实配置，AI默认关闭 | 团队共享密钥的调用计入同一账户 |
| 连接与效果评估 | 单次真实连接检查、次数受限批量评估、指标与人工复核字段 | 工具已实现；真实运行及人工复核仍需完成 |
| 跨平台入口 | macOS启动.command、Windows启动.bat、Linux启动.sh；环境检查与CI定义 | 需Python 3.10+和Tkinter；Windows/Linux代码判题另需Docker |

## 待完成的验收

- 真实Kimi连通性及诊断/讲解效果：运行工具并检查报告，不把模拟测试当作真实效果。
- 题库、提示及误区标签的人工交叉复核。
- 团队独立代码审查与修复复核记录。
- Windows/Linux实机或CI验收；本机已验证macOS，Docker仅完成模拟分支测试。

## 可选后续功能

编程历史回放、对代码错误的AI辅导、多轮追问尚未实现，均不影响当前选择题和基础编程主流程。任意学科、拍照识题、复杂账号和多人同步、模型训练不在本轮范围。教师端已从范围中移除，不再列为缺失功能。
