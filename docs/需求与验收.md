# 功能规格与验收

## 范围

用户为 Python 初学者。三个主题：条件判断、循环、函数与返回值。核心流程是选主题→答题→诊断→练习→记录→回顾。

| 编号 | 要求 | 验收操作与预期 |
|---|---|---|
| F01 | 按主题答题 | 切换三个主题，题目内容随之变化，均有三个选项 |
| F02 | 标准答案评分 | 正确选项显示正确，错误选项显示错误；空选项不能提交 |
| F03 | 可能性诊断 | 错误答案显示候选概念和选择依据，不表述为确定掌握情况 |
| F04 | 推荐变式 | 答错后第一条推荐是尚未做过的同概念不同题 |
| F05 | 题库耗尽 | 所有同主题题做完后，推荐标注复习题且排除当前原题 |
| F06 | 持久化 | 提交后重启，记录与统计保留；单道题一次提交不会重复入库 |
| F07 | 错题回顾 | 默认仅看错误记录，取消筛选可看全部；可重新练习 |
| F08 | 理由输入 | 可留空，超过1000字拒绝提交，学生文本不作为代码执行 |
| F09 | AI 降级 | 未配置模型、模型响应无效或网络失败时仍能评分并保存 |
| F10 | 学习进度 | 两道不同题近期答对才标为初步稳定；近期错误显示仍需练习 |
| F11 | 导出 | 导出的 JSON 与数据库全部作答记录一致，保留理由和 AI 状态 |
| F12 | 非阻塞 | AI 后台分析期间窗口仍可响应，禁止切题或重复提交 |

## 数据

Question：id、topic、concept、difficulty、prompt、code、options、answer、explanation、hint、misconceptions、review_status。

Attempt：自增 id、question_id、choice、reason、correct、规则 diagnosis、ai_json、UTC created_at；界面按本地时间显示。

Concept：主题、名称、教学提示。题库作为版本化只读数据加载，学习记录写入 SQLite。

## 不在范围内

拍照识题、任意代码沙箱、开放学科诊断、模型训练、多用户登录、实时协作、证明长期学习成绩提高。
